# Subscription Health Monitor

A Python dashboard project for synthetic SaaS subscription analytics, health scoring, outlier detection, and churn risk monitoring.

## What it does

- Generates synthetic subscription customer data in `data/subscriptions.csv`
- Computes customer health scores and MRR metrics using DuckDB and pandas
- Detects revenue outliers and churn risk
- Displays results in a Streamlit dashboard

## Project structure

- `app.py` — Streamlit dashboard with MRR overview, customer health, outlier detection, and churn risk pages
- `data/generate_data.py` — generates synthetic subscription data
- `data/` — precomputed CSV data used by the app
- `notebooks/02_sql_analysis.ipynb` — SQL analysis for MRR, health scores, and outliers
- `notebooks/03_ml_churn.ipynb` — churn model notebook using RandomForest
- `.streamlit/config.toml` — Streamlit light theme configuration

## Setup

1. Create and activate the virtual environment:
   ```powershell
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   ```

2. Install dependencies:
   ```powershell
   python -m pip install -r requirements.txt
   ```

3. Generate data (optional if you want fresh data):
   ```powershell
   python data/generate_data.py
   ```

4. Run the dashboard:
   ```powershell
   streamlit run app.py
   ```

## Notes

- The `app.py` dashboard loads precomputed data from `data/`.
- `data/at_risk_customers.csv` is generated from the current risk score logic.
- `churn_probability` is derived from health score when not generated by the churn model notebook.
- The theme is set to a light mode in `.streamlit/config.toml`.
